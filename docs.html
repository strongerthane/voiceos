Quick start

Download VoiceOS.exe, run it, and grant microphone access when prompted. VoiceOS lives in your system tray and listens for your wake word or a hotkey.

First run: VoiceOS builds its app index on first launch. This takes a few seconds — app launching will be instant after that.

Voice commands

SayWhat happens
"Open Spotify"Launches Spotify (or the best local match).
"Search for weather in Seattle"Searches the web and opens your browser.
"Capture my screen"Captures screen context via the laser pointer.
"Organize my downloads folder"Runs the file-organization plugin.
"Stop" / "Cancel"Interrupt controller halts the current action.

Screen context (laser pointer)

VoiceOS captures what's on your screen with a mouse-trail based pointer — no boxes, no overlays. Captures are saved to audio_captures/ alongside local audio recordings.

Plugins

VoiceOS uses an AJR architecture: config, event bus, orchestrator, guardrails, voice pipeline, TTS, interrupt controller, session shell, distributed worker, and sandbox. Plugins run sandboxed for workflows, scheduling, TTS, and file organization.

Troubleshooting

IssueFix
VoiceOS doesn't hear meCheck microphone permissions in Windows Settings > Privacy > Microphone.
App won't launch by voiceRebuild the app index from the VoiceOS menu, or use the exact app name.
Screen capture blankEnsure display scaling is 100–150% and graphics drivers are current.
Download link not availableVoiceOS.exe is published as a GitHub Release asset. Check back or build locally from the repo.
