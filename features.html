Features

VoiceOS is a voice-first desktop assistant for Windows. Here is what your voice can do.

App discovery & launching

Open any desktop app by name. VoiceOS searches your installed applications, the internet, and falls back to the browser when nothing local matches. Say "Open Spotify" or "Search for weather in Seattle". It just works.

  • Launch installed Windows apps by voice
  • Internet search with browser fallback
  • Fuzzy app-name matching

Scene: You're in the middle of work and need an app open without breaking flow. One sentence, no menu diving.

Screen context capture (laser pointer)

Capture what's on your screen with a mouse-trail based pointer. No boxes, no overlays, no clutter. VoiceOS records the context so your next voice command knows what you're looking at.

  • Mouse-trail based screen capture
  • No bounding boxes or UI chrome
  • Audio captures saved to audio_captures/

Scene: Show VoiceOS what you're looking at, then ask a question about it. Context carries across your conversation.

Local voice pipeline

faster-whisper runs locally for fast, private speech-to-text. Google/Gemini STT acts as a fallback when local confidence is low. Hallucination filtering keeps responses grounded, and local audio capture lives in audio_captures/.

  • faster-whisper STT (local, private)
  • Google/Gemini STT fallback
  • Whisper hallucination filtering
  • Local audio capture to audio_captures/

Scene: Voice processing stays local by default. Cloud fallback only when you need it.

Smart plugins

Extend VoiceOS with plugins for workflows, scheduling, TTS, and file organization. The AJR architecture (config, event bus, orchestrator, guardrails, voice pipeline, TTS, interrupt controller, session shell, distributed worker, sandbox) keeps every plugin isolated and safe.

  • Workflows & scheduling
  • Text-to-speech (TTS)
  • File organization
  • Sandboxed plugin execution

Scene: "Organize my downloads folder" or "Schedule a reminder for 3 PM". Plugins handle it, sandboxed.

Built to be interrupted

VoiceOS has an interrupt controller and guardrails built in. Stop a command mid-sentence, cancel an action, or override an automation. You stay in control.
